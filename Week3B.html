Overall average maximum temp and differentials

I computed the average maximum temperature for the entire data set (max_avg), as well as the daily differences (max_differential) between the maximum daily temperatures and the normal maximum daily temperature (normal_max).

Note that I don’t use OVER () in the line: ROUND(max - normal_max), 1) since I am not calculating over multiple rows. The computation is done using values within each row rather than across all the rows of the table.

temp_NY <- dbGetQuery(con, "
  SELECT
  date,
  max,
  normal_max,
  ROUND(AVG(max) OVER (), 1) AS max_avg,
  ROUND(max - normal_max, 1) as daily_max_differential
  FROM \"globalWarming\"
  ORDER BY date
") |>
  as_tibble()

Average maximum temperature differential by year

I find SQL to be very unintuitive, and this code for finding the average maximum temperature differentials by year gave me lots of problems. I needed Google AI to assist with debugging. The main problems were getting the year into proper date format, and since I foolishly included a capital letter in my data set name, SQL required quotes around the title. This confused R since a quote already appears in the first line of code, so I had to escape the quotes around the title with a backslash.

temp_NY <- dbGetQuery(con, "
  SELECT
  EXTRACT(YEAR FROM TO_DATE(date, 'YYYYMMDD')) AS year_NY,
  ROUND(AVG(max - normal_max), 1) AS yearly_max_differential
  FROM \"globalWarming\"
  GROUP BY year_NY
  ORDER BY year_NY
") |>
  as_tibble()

Rank each year by temperature differential

Well here is something finally useful! We see that most of the years with average high temperatures that exceeded normal high temperatures occurred in the 2000s.

temp_NY <- dbGetQuery(con, "
  SELECT
  EXTRACT(YEAR FROM TO_DATE(date, 'YYYYMMDD')) AS year_NY,
  ROUND(AVG(max - normal_max), 1) AS yearly_max_diff,
  RANK() OVER (
  ORDER BY AVG(max - normal_max) DESC) AS temp_rank
  FROM \"globalWarming\"
  GROUP BY year_NY
  ORDER BY temp_rank
") |>
  as_tibble()

Conclusion: DPLYR > SQL

SQL is maddeningly difficult to work with. My main takeaway from this assignment is that if you have to do any sort of data manipulation on a data frame, do it in R. For example, if I want to find the maximum daily temperature within each year and rank them from hottest to least hot, I would have no idea how to do that with SQL. In R, it’s just a few simple lines of code.

First, import the table:

Then, convert the date variable into year-month-day format; create a new column to hold the years data; remove all rows pertaining to years after 2026; collapse all rows by years and find the max temperature for each year; and finally, sort. Nice and simple.

library(dplyr)
library(lubridate)

temp_NY <- temp_NY %>%
  mutate(
    date = ymd(date),
    year = year(date)) %>%
  filter(year < 2027) %>%
  group_by(year) %>%
  summarize(max_temp = max(max, na.rm = TRUE)) %>%
  arrange(desc(max_temp))
